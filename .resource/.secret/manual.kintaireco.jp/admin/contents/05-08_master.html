部署の登録

部署名を登録します。

登録した部課マスタは、［従業員マスタ］および［承認経路マスタ］の部課設定で使用します。

［共通マスタ］の「申請機能」を「使用する」にした場合、登録は必須です。

登録は［部課マスタ］画面で実施します。

ご注意

部課マスタを操作できるのは、システム管理者アカウントのみです。

部課マスタを登録する

  1. ［マスタ］をクリックし、［部課マスタ］をクリックする

    「部課マスタ」画面が表示されます。

  2. ［新規作成］ボタンをクリックする

    「部課マスタ新規作成」画面が表示されます。

  3. 各項目を入力する

    1. 部課コード

      部課コードを入力します。設定後の変更はできません。（半角数字、最大8文字）

      マスタ一覧ではコード順でマスタが表示されます。

    2. 部課名

      部課名を入力します（最大255文字）。

  4. ［登録する］ボタンをクリックする

    画面上部に「登録が完了しました。」とメッセージが表示され、入力した部課マスタ情報がマスタデータに登録されます。

    ヒント

    追加で新規に部課マスタを登録する場合は、登録済みの部課マスタをコピーして修正することもできます。

    「部課マスタ」画面で、コピーしたい部課の行の右側にある［複写］ボタンをクリックし、必要情報を修正して登録してください。

部課マスタを確認・編集・削除する

  1. ［マスタ］をクリックし、［部課マスタ］をクリックする

    「部課マスタ」画面が表示されます。

  2. 必要に応じて、部課名を検索する

    削除した部課を検索する場合は「削除済みを含む」にチェックを付けます。

  3. 編集したい部課マスタの［編集］をクリックする

    「部課マスタ-編集」画面が表示されます。

    ヒント

    • ［詳細］をクリックすると、選択した部課マスタの登録内容を確認できます。確認が済んだら［一覧へ戻る］ボタンで「部課マスタ」画面に戻ります。

    • ［削除］をクリックすると、選択した部課マスタを削除します。

  4. 変更したい項目を修正する

  5. ［更新する］をクリックする

    画面上部に「更新が完了しました。」とメッセージが表示され、部課マスタの変更情報がマスタデータに登録されます。

    削除を元に戻したい場合は、「削除済みを含む」にチェックを付けて検索し、「部課マスタ-編集」画面で削除済みチェックを外して登録してください。


つづけて「役職名の登録」に進んでください。
