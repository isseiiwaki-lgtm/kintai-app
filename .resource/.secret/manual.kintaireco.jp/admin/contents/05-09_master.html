役職名の登録

役職名と役職優先順位を登録します。

登録した役職マスタは、［従業員マスタ］の役職設定、［承認経路マスタ］の承認者・決裁者設定で使用します。

［共通マスタ］の「申請機能」を「使用する」にした場合、登録は必須です。

登録は［役職マスタ］画面で実施します。

ご注意

役職マスタを操作できるのは、システム管理者アカウントのみです。

役職マスタを登録する

  1. ［マスタ］をクリックし、［役職マスタ］をクリックする

    「役職マスタ」画面が表示されます。

  2. ［新規作成］ボタンをクリックする

    「役職マスタ-新規作成」画面が表示されます。

  3. 各項目を入力する

    1. 役職コード

      役職コードを設定します。設定後の変更はできません。（一意／最大255文字）

      マスタ一覧ではコード順でマスタが表示されます。

    2. 役職名

      役職名を設定します（最大255文字）。

    3. 優先順位

      従業員マスタでの表示順位を設定します（最大8文字）。

      従業員マスタで役職を登録する際に、役職マスタの優先順位で選択肢に表示されます。

      ※優先順位の数値は、優先順位の高さに比例します（数値が大きいほど優先順位も高くなります）。

  4. ［登録する］ボタンをクリックする

    画面上部に「登録が完了しました。」とメッセージが表示され、入力した役職マスタ情報がマスタデータに登録されます。

    ヒント

    追加で新規に役職マスタを登録する場合は、登録済みの役職マスタをコピーして修正することもできます。

    「役職マスタ」画面で、コピーしたい役職の行の右側にある［複写］ボタンをクリックし、必要情報を修正して登録してください。

役職マスタを確認・編集・削除する

  1. ［マスタ］をクリックし、［役職マスタ］をクリックする

    「役職マスタ」画面が表示されます。

  2. 編集したい役職マスタの［編集］をクリックする

    削除した役職を検索する場合は「削除済みを含む」にチェックを付けます。

    ヒント

    • ［詳細］をクリックすると、選択した役職マスタの登録内容を確認できます。確認が済んだら［一覧へ戻る］ボタンで「役職マスタ」画面に戻ります。

    • ［削除］をクリックすると、選択した役職マスタを削除します。

    「役職マスタ-編集」画面が表示されます。

  3. 変更したい項目を修正する

  4. ［更新する］をクリックする

    画面上部に「更新が完了しました。」とメッセージが表示され、役職マスタの変更情報がマスタデータに登録されます。

    削除を元に戻したい場合は、「削除済みを含む」にチェックを付けて検索し、「役職マスタ-編集」画面で削除済みチェックを外して登録してください。


つづけて「勤務形態の登録」に進んでください。
