# 勤怠管理システム 利用マニュアル

## 1. ログイン

会社から案内された Google アカウント（会社メールに紐づけたもの）でログインします。

1. ログイン画面で「**Google でログイン**」をタップ
2. Google アカウントを選択してください
3. 初回ログイン時は「会社メールアドレスの確認」画面が表示されます。会社から配布されたメールアドレスを入力して登録してください

> **注意:** 個人の Gmail など、会社に登録していないアカウントではログインできません。

---

## 2. ホーム画面の見方

ログイン後に表示されるホーム画面には、主に3つの情報が表示されます。

### 今日の勤務
今日の出勤時刻・退勤時刻・勤務時間と、現在の状態（未出勤 / 出勤中 / 退勤済）を確認できます。
ホーム画面から直接「**出勤する**」「**退勤する**」ボタンをタップして打刻することもできます。

### 今月の実績
当月（締め日基準）の出勤日数と合計勤務時間を確認できます。

### お知らせ（インフォメーション欄）
以下のような場合にお知らせが表示されます。確認して対応してください。

| 表示内容 | 意味 | 対応 |
|---|---|---|
| 🔴 退勤打刻がありません | 打刻漏れの可能性 | 「修正依頼」から申請 |
| 🟠 却下された申請があります | 申請が却下された | 申請一覧を確認 |
| 🟡 未確認の勤怠があります | 要確認の打刻記録がある | 勤怠記録を確認・修正依頼 |
| 🔵 審査中の申請があります | 申請が処理待ち | そのまま待つ |

## 3. 打刻する

毎日の出勤・退勤は「**打刻**」画面から行います。サイドバーの「打刻」をタップしてください。

### 出勤時
職場に到着したら「**出勤**」ボタンをタップします。

### 退勤時
業務終了後に「**退勤**」ボタンをタップします。

### 外出・戻り
業務中に外出する場合は「**外出**」ボタンをタップします。戻ったら「**戻り**」ボタンをタップします。

### 休憩（パート・アルバイトの方）
休憩に入る前に「**休憩開始**」、戻ったら「**休憩終了**」をタップします。

> **ポイント:** 打刻はなるべくその場でリアルタイムに行ってください。打刻忘れや時刻の誤りは「修正依頼」から申請できます（→ [6章](#6-修正依頼をする)）。

---

## 4. 勤怠記録を確認する

サイドバーの「**勤怠記録**」から、自分の月次打刻一覧を確認できます。

- **◀ ▶** ボタンで前月・翌月に切り替えられます
- 表示期間は締め日に応じて変わります（例: 25日締めの場合、「4月」は3/26〜4/25を表示）
- 遅刻・打刻漏れの可能性がある行は **オレンジ色** で表示されます

### 状態バッジの意味

| バッジ | 意味 |
|---|---|
| 打刻済 | 打刻されているが確認前 |
| 要確認 | 遅刻・早退・打刻漏れの可能性がある |
| 申請中 | 修正依頼が審査中（管理者が処理するまで待つ） |
| 修正済 | 修正依頼が承認された |
| 承認済 | 管理者が承認した |
| 締め済 | 月次締め処理が完了した（変更不可） |
| 欠勤 | 欠勤申請が承認された |

## 5. 各種申請をする

サイドバーの「**申請**」→「**新規申請**」から申請を作成できます。申請には以下の種類があります。

### 残業申請
所定時間を超えて勤務する場合に申請します。残業終了予定時刻を選択してください。

### 早出申請
通常より早く出勤する場合に申請します。早出開始時刻を選択してください。

### 遅刻・早退申請
遅刻または早退が確定した時点で申請します。種別（遅刻 / 早退）と時刻を選択してください。

### 欠勤申請
体調不良などで終日休む場合に申請します。承認されると勤怠記録に「欠勤」と記録されます。

### 有給休暇申請
有給休暇を取得する場合に申請します。全休・午前半休・午後半休から選択できます。

### 代休申請
休日出勤の振替として代休を取得する場合に申請します。代休取得日と振替元の出勤日を入力してください。

### 申請の取り下げ
審査中（管理者が処理する前）であれば、申請一覧から「**取り下げ**」ができます。承認済みの申請は管理者にお問い合わせください。

## 6. 修正依頼をする

打刻を忘れた・時刻が間違っているなど、打刻の修正が必要な場合は「修正依頼」を申請します。

### 勤怠記録から申請する（おすすめ）

1. サイドバーの「**勤怠記録**」を開く
2. 修正したい日付の行に表示されている「**修正依頼**」ボタンをタップ
3. 修正の種類を選択する
   - **遅刻・早退**: 出勤・退勤の実際の時刻が正しくない場合
   - **打刻漏れ**: 打刻を忘れた場合
4. 必要事項を入力して申請する

申請後は状態バッジが「**申請中**」に変わり、「修正依頼」ボタンが非表示になります。管理者が承認すると「**修正済**」に変わります。

### 申請フォームから申請する

「新規申請」→「打刻修正申請」を選択し、修正したい項目（出勤 / 退勤 / 外出 / 戻りなど）と修正後の時刻を選択してください。

## よくある質問

**Q. ログインできない**
会社に登録しているメールアドレスと、Google アカウントの紐づけが完了しているか確認してください。不明な場合は管理者にお問い合わせください。

**Q. 打刻を押し忘れた**
修正依頼を申請してください（→ [6章](#6-修正依頼をする)）。申請理由に状況を詳しく記載してください。

**Q. 申請が却下された**
ホーム画面または申請一覧でお知らせを確認してください。却下理由を確認し、必要であれば再申請してください。

**Q. 勤怠記録の内容がおかしい**
管理者または申請フォームからお問い合わせください。締め済みの記録は管理者が対応します。
