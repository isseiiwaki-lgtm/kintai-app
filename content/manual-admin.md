# 勤怠管理システム 管理者マニュアル

> 計算がおかしい・画面にエラーが出るなど、システムの不具合かもしれないときは、システム管理者に連絡してください。記録や申請の誤りの修正・扱いの相談は、労務管理者が対応します。

## 1. 管理者ロールについて

| 機能 | APPROVER | ADMIN |
|---|---|---|
| 勤務状況閲覧 | ○ | ○ |
| 勤怠承認・承認取消 | ○ | ○ |
| 申請承認・却下 | ○ | ○ |
| 締め・締め解除 | — | ○ |
| 承認経路の管理 | — | ○ |
| ユーザー管理 | — | ○ |
| 会社設定 | — | ○ |

---

## 2. 勤務状況一覧

全ユーザーの月次勤務状況（出勤日数・労働時間・残業・未承認件数）を一覧表示します。

- **◀ ▶** で月を切り替えられます（締め日連動集計）
- ユーザー名をクリックすると個人詳細（勤怠承認画面）へ移動します
- 「管理者」「管理職」部署のユーザーは一覧から除外されます
- 該当する日があるときだけ、「休憩記録なし」（パート）「休日申請なし」の列が表示されます

---

## 3. 勤怠承認

### 承認と締めは必ず行ってください

```
打刻済（未承認）→ 承認 → 承認済 → 締め → 締め済
```

- 承認するときに、その日の勤務時間・遅刻・早退・残業を最新の決まりで計算し直して保存します。**承認・締めをしないまま参考にすると、数字がずれていることがあります**
- **毎月必ず締めてください**。締めていない記録は、個人の設定を変えたときやシステムの更新のときに計算し直されます。締めた記録は変わりません
- 締めた後でも、ADMIN は「締め解除」で承認済みに戻せます（変更履歴に残ります）
- 締めの前に、**審査中の打刻修正申請と残業申請を処理してください**。処理しないと、打刻漏れの日が勤務0のまま、残業が定時で打ち切られたまま確定します（④がONのとき、残業は承認された残業申請の終了時刻までしか数えません。申請が承認された時点で計算し直されますが、締めた記録は計算し直されません）

### 承認一覧画面

- **承認**: その月の未承認の記録をすべて承認します
- **承認取消**: 承認済みの記録を未承認に戻します
- **締め**（ADMIN のみ）: 承認済みの記録をすべて締めます
- **詳細 →**: 個人の日次一覧へ移動します
- 一覧の上の **全員を承認／全員の承認取消／全員を締め**（締めは ADMIN のみ）で、その月の全員分をまとめて処理できます。先に1人ずつ申請と記録を確認してから使ってください（押すと確認が出ます）

### 個人詳細画面

- 行をクリックすると **編集画面** が開きます。出勤・退勤・外出・戻り・**休憩（分）**・**休日出勤（代理）**を直せます。管理者が直した時刻は丸めずにそのまま記録し、保存すると承認済みになります
- **管理者の修正を取り消す**: 管理者が直した時刻を、1つ前の状態に戻せます
- **代理打刻**: 出勤も退勤も打刻が無かった日に、後から記録を作ります（対象日の候補が自動で出ます。保存後は承認済み）
- 記録の時刻と実際に押した時刻が違う日は、「実 8:42」のように併記します
- 「申請あり」から当日の申請を確認できます
- タイムカードと休憩が違う日は、編集画面の「休憩（分）」に正しい分数を入れてください

## 4. 申請承認

### 審査中・処理済み

- **承認** / **却下** / **修正**（申請内容を直す）/ **削除**ができます
- 処理済みは、申請者順と対象日順を切り替えられます

### 多段階承認

承認経路（→ 5章）を設定した部署の申請は、step 順に承認が必要です。進捗が「1/2」のように表示され、担当外の step は操作できません。ADMIN は「飛び越し承認」で残りの step をまとめて承認できます。

### 申請種別と承認時の動作

| 種別 | 承認時の動作 |
|---|---|
| 打刻修正 | 打刻の時刻を直し、勤務時間などを計算し直す |
| 残業 | 退勤の記録を申請の終了時刻までにする（④ON のとき）。パートは申請の時間を残業として数える |
| 早出 | 定時より前の出勤を早出として記録する（④ON のときは申請の開始時刻より前は数えない） |
| 遅刻・早退 | その日の「要確認」（遅刻・早退）を消す。正社員の早退は、申告した休憩をその日の休憩にする |
| 欠勤 | その日を欠勤にする |
| 有給 | 有給の日として記録する（日数：全休1・半休0.5） |
| 休憩 | その日の休憩の合計を申請の分数にする |
| 休日出勤 | 申請の開始〜終了をその日の定時にし、申請の休憩を入れる。振休・代休の休む日を記録する |

---

## 5. 承認経路（ADMIN のみ）

部署ごとに、申請の承認の順番（step）と承認者を登録します。経路が無い部署は一段階承認です。

- 同じ step に複数の承認者を追加すると、**そのうち誰か1名**が承認すれば次の step へ進みます。全員の承認が必要なときは step を分けてください
- 承認者を入れ替えるときは、新しい人を追加してから古い行を削除します
- 経路は**申請者の部署**で決まります。部署名を変える（統合する）ときは、先に承認者の部署を変えて新しい部署の経路を登録し、その後で他の人の部署を変えてください

## 6. 会社設定（ADMIN のみ）

| 項目 | 説明 |
|---|---|
| 締め日 | 月次集計の区切り日（例: 25 → 前月26日〜当月25日） |
| 休憩時間控除ルール | 所定休憩が登録されていない人の休憩を、定時の長さから決めます（ルール1：○分超で○分、ルール2：○分超で○分）。勤務時間の長さから決めることはしません |
| 昼休憩の開始時刻 | 半休の前半・後半の境目に使います |
| ① 定時前打刻 → 定時扱い | 定時より前の出勤を定時で記録します |
| ② 定時14分以内の早出・残業 → 定時きっかり | 定時から14分以内の早出・残業を定時にそろえます。遅刻・早退側は丸めません |
| ③ 全体の15分丸め | 出勤は切り上げ、退勤は切り捨てで15分にそろえます |
| ④ 残業は申請した終了時刻を上限に記録する | 残業申請の終了時刻（無ければ定時）で退勤の記録を打ち切ります |
| ⑤ 新しい計算方式 | 正社員の残業を「早出＋定時後」で数えます |

> **注意:** スイッチ・締め日は、締め期間の初日に切り替えてください。月の途中で変えると、同じ月に違う計算が混ざります。スイッチの状態は記録ごとに保存され、切り替えても過去の記録は変わりません。

## 7. ユーザー管理（ADMIN のみ）

### 主な設定項目

| 項目 | 説明 |
|---|---|
| 従業員コード | 数字のみ・重複不可。変えるときは、給与ソフト側の対応も手で直してください |
| 雇用形態 | 正社員 / パート など |
| 定時（出勤・退勤時刻） | 遅刻・早退の判定に使います。**パートで勤務時間帯が日によって変わる人（シフト勤務）は空欄にしてください**（遅刻・早退を判定せず、本人が遅刻申請を出します） |
| 所定休憩（分） | ふだん取る休憩。記録が無い日はこの分数を引きます。空欄なら会社設定の休憩時間控除ルールで決めます |
| フルタイムパート | 半日有給を取れるパート |
| 所定出勤曜日 | 休みの曜日の判定に使います |


### 新入社員の登録の流れ

社員は、会社のメールアドレスの Google アカウントでログインします。アカウントの用意と勤怠システムへの紐づけまでを、管理者が済ませてから本人に渡してください。

1. **会社のメールアドレスの発行を、システム管理者に依頼する**
2. **発行されたメールアドレスで、業務用の Google アカウントを作る**
3. **勤怠システムに新入社員を登録する**：ユーザー管理の「新規登録」（または近い条件の社員の「複製」）で、ログイン用メールと会社メールに、作ったメールアドレスを入れる。定時・所定休憩・雇用形態なども設定する
4. **作った Google アカウントで勤怠システムにログインし、紐づけを済ませる**
   - **自分（管理者）のログインのままでは行わないでください。** 勤怠システムからログアウトするか、ブラウザのシークレットウィンドウを使います（ログインしたままだと、自分の画面が開くだけで新入社員の紐づけはできません）
   - 作った Google アカウントでログインし、新入社員のホーム画面が表示されれば紐づけ完了です。ログイン画面にエラーが出たら、その内容をシステム管理者に連絡してください
5. メールアドレス・Google アカウントのパスワードを本人に渡す

### 個人の勤務条件を変えるとき

定時・所定休憩・雇用形態・所定出勤曜日を変えると、**まだ締めていない記録すべて**が新しい条件で計算されます（条件は記録ごとには保存されません）。締め期間の途中で変えると、変える前の日まで新しい条件で計算されます。

- **原則として、締め期間の初日（26日）に変えてください**
- 勤務の都合でどうしても途中から変わるときは、次のようにしてください
  1. **変わった日と、変更前・変更後の内容を記録し、労務管理者に伝える**
  2. 設定を変える
  3. **次の給与計算（その期間の承認）の前に、下の項目が変更どおりになっているかを必ず確認し、必要なら直す**。承認すると、その期間の記録が新しい条件で計算し直されます。変わる前の日の数字が違っていれば、承認詳細の編集で直してください

| 変える項目 | 次の給与計算で変わること |
|---|---|
| 定時（出勤・退勤時刻） | 所定（定時の長さ − 休憩）、遅刻・早退の判定、残業の基準（正社員は定時の外、パートは残業申請の開始＝定時の終業）、半休の前半・後半の境目 |
| 所定休憩 | 休憩の記録が無い日に引く休憩、所定 |
| 雇用形態 | 残業の数え方（正社員とパートで違う）、休憩ボタンの有無 |
| 所定出勤曜日 | 休みの日の判定（休日出勤申請が必要な日） |

### CSVインポート

「CSVインポート」ボタンから複数ユーザーを一括登録できます。既存の従業員コードは上書き更新されます。

## 8. 休憩と残業の決まり

### 休憩の決め方

その日に休憩したかどうかを、**勤務時間の長さから推測することはしません**。次の順に決めます。

1. **その日の申告**：休憩ボタン（パート）、承認された休憩申請・早退申請の休憩、管理者が承認詳細で入力した休憩
2. 1が無い日は、**本人と事前に決めている休憩**：ユーザー管理の「所定休憩」（正社員・パートとも）
3. 2が未設定の人は、**本人の定時の長さ**に、会社設定の休憩時間控除ルールを当てて決める（定時が無い人は休憩なし）

- 早退した日・残業した日も、休憩は上の決め方のままです（例：15時に早退しても、休憩は60分のまま。正社員は早退申請で休憩を取ったかを答えます）
- 定時が短い人が残業して長く働き、休憩を取ったときは、本人が休憩を申請します
- 休日に休日出勤申請が承認されていない日は、休憩0です（休日の勤務と休憩は、申請の承認で決まります）

| 人 | 条件 | 休憩 |
|---|---|---|
| パート 9:00〜16:00 | 所定休憩60分・記録なし | 60分 |
| パート 12:30〜16:30 | 所定休憩なし・定時4時間・記録なし | 0分 |
| 同上 | 長く働き、休憩30分を申請して承認された | 30分（申請が優先） |
| 正社員 9:00〜18:00 | 15:00に早退・早退申請で「60分取った」 | 60分 |
| 正社員 9:00〜17:00 | 所定休憩なし | 会社設定のルールの値（60分） |

### パートの定時

- **定時を登録した人**：定時をもとに遅刻・早退を判定します
- **勤務時間帯が日によって変わる人（シフト勤務）**：定時を空欄にします。遅刻・早退を判定せず、遅れたときは本人が遅刻申請を出します。残業申請では、残業の開始時刻も入力します

### 残業

- **正社員**：定時の外で働いた時間（早出＋定時後）。④がONなら、残業申請の終了時刻まで
- **パート**：定時を過ぎただけでは付きません。「1日8時間を超えた分」と「承認された残業申請の時間」だけです（重なる時間は1回だけ数えます）

## 9. Excel（個人別日別勤務報告書）

| 列 | 意味 |
|---|---|
| 出勤・退勤 | 実際に押した時刻（打刻が無ければ空欄） |
| 勤務時間 | 記録の時刻（丸め・修正を反映した時刻）の時間帯 |
| 変更出勤・変更退勤 | 出勤・退勤を直した日だけ表示 |
| 遅刻早退 | 「遅 0:30」「早 2:00」のように表示 |
| 有給 | 日数（全休1・半休0.5）。時間は給与システムで計算します |

- パートの残業は「1日8時間を超えた分」と「承認された残業申請の時間」だけです
- 週40時間を超えた分などの割増の振り分けは、給与システムで行ってください

## 10. 休日カレンダー

会社の休日を登録します。「祝日シード」で日本の祝日を一括登録できます。個別に日付を追加・削除することもできます。

---

## 11. 変更履歴

管理者による打刻の変更（編集画面での修正・代理打刻・締め解除など）を月別に確認できます。変更前後の値と操作者が記録されます。
