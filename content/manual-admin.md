# 勤怠管理システム 管理者マニュアル

## 1. 管理者ロールについて

| 機能 | APPROVER | ADMIN |
|---|---|---|
| 勤務状況閲覧 | ○ | ○ |
| 勤怠承認・承認取消 | ○ | ○ |
| 申請承認・却下 | ○ | ○ |
| 一括締め | — | ○ |
| ユーザー管理 | — | ○ |
| 会社設定 | — | ○ |

---

## 2. 勤務状況一覧

全ユーザーの月次勤務状況（出勤日数・労働時間・残業・未承認件数）を一覧表示します。

- **◀ ▶** で月を切り替えられます（締め日連動集計）
- ユーザー名をクリックすると個人詳細（勤怠承認画面）へ移動します
- 「管理者」「管理職」部署のユーザーは一覧から除外されます

---

## 3. 勤怠承認

### 承認フロー

```
打刻済（未承認）→ 承認 → 承認済 → 締め → 締め済
```

| ステータス | 意味 |
|---|---|
| 未承認 | ユーザーが打刻したが管理者未確認 |
| 承認済 | 管理者が承認済み |
| 締め済 | 月次締め処理完了（変更不可） |

### 承認一覧画面

全ユーザーのステータス件数を一覧表示します。各行に以下のボタンがあります。

- **承認**: その月の未承認レコードをすべて承認済みにします
- **承認取消**: 承認済みレコードをすべて未承認に戻します
- **締め**（ADMIN のみ）: 承認済みレコードをすべて締め済みにします
- **詳細 →**: 個人の日次一覧へ移動します

### 個人詳細画面

日次の打刻データを確認・編集できます。

- 行をクリックすると **編集モーダル** が開きます（出勤・退勤・外出・戻り・休憩の時刻を修正可能）
- 保存すると自動的に承認済みステータスになり、労働時間・遅刻・残業等が再計算されます
- 「申請あり」リンクから当日の申請内容を確認できます
- **一括承認**: 未承認レコードをすべて承認します
- **一括締め**（ADMIN のみ）: 承認済みレコードをすべて締めます

---

## 4. 申請承認

ユーザーからの申請を一覧表示します。

### 審査中

未処理の申請をすべて表示します。各申請に以下の操作が可能です。

- **承認**: 申請内容を承認します。打刻修正申請の場合は打刻データが自動更新されます
- **却下**: 申請を却下します。ユーザーのホーム画面にお知らせが表示されます
- **修正**: 申請内容を修正して承認します（打刻修正申請の時刻を変更する場合など）

### 処理済み

月を選択して過去の処理済み申請を確認できます。修正・削除も可能です。

### 申請種別と承認時の動作

| 種別 | 承認時の動作 |
|---|---|
| 打刻修正 | 指定時刻で打刻データを自動更新・労働時間を再計算 |
| 残業・早出 | 申請記録のみ（打刻データは変更しない） |
| 欠勤 | 当日レコードに「欠勤」フラグを付与 |
| 遅刻・早退・有給・代休 | 申請記録のみ |

## 5. 会社設定

ADMIN のみ変更できます。

| 項目 | 説明 |
|---|---|
| 締め日 | 月次集計の区切り日（例: 25 → 前月26日〜当月25日） |
| 休憩控除ルール | フルタイムの自動休憩控除時間を設定 |
| 定時前打刻→定時扱い | ON にすると定時前の出勤打刻を定時に丸める |
| 定時±14分→定時きっかり | ON にすると定時の前後14分以内の打刻を定時に丸める |

> **注意:** 締め日変更は既存の集計期間に影響します。月初などの適切なタイミングで変更してください。

---

## 6. ユーザー管理

ユーザーの追加・編集・削除および CSV での一括管理ができます。

### 主な設定項目

| 項目 | 説明 |
|---|---|
| 従業員コード | 数字のみ（重複不可） |
| 雇用形態 | フルタイム / パート / 雇用者（所定時間0扱い） |
| 所定勤務時間 | 出勤時刻・退勤時刻を設定（残業・遅刻計算に使用） |
| 所定出勤曜日 | 月〜金をデフォルトとして個別設定可 |
| 会社メール | 通知・識別に使用（Google アカウントと別に設定可能） |

### CSVインポート

「CSVインポート」ボタンから複数ユーザーを一括登録できます。既存の従業員コードは上書き更新されます。

---

## 7. 休日カレンダー

会社の休日を登録します。

- **祝日シード**: 日本の祝日を一括登録します
- 個別に日付を追加・削除することもできます

---

## 8. 変更履歴

管理者による打刻変更（編集モーダルでの修正）の操作ログを月別に確認できます。変更前後の時刻と操作者が記録されます。
