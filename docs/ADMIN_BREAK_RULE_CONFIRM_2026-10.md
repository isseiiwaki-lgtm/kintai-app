# 休憩時間の考え方について（ご確認のお願い）

リリース2〜3を含む今回の変更点（運用手順の変更）の一部です。**この部分だけ先にご確認ください。** 内容に違いがあれば、システムに反映する前に直します。

## 1. 休憩時間の決め方

その日に休憩したかどうかを、**勤務時間の長さから推測することはしません**。次の順に決めます。

1. **その日の申告**：休憩ボタン、承認された休憩申請、管理者が承認画面で入力した休憩
2. 1が無い日は、**本人と事前に決めている休憩**：ユーザー管理の「所定休憩」（正社員・パートとも）
3. 2が未設定の人は、**本人の定時の長さ**で決める：定時が6時間を超える人は60分、6時間以下の人は休憩なし

- 休憩は与える場合は一律60分です（45分にはしません）
- 早退した日・残業した日も、休憩は上の決め方のままです。たとえば15時に早退しても、休憩は60分のままです
- 定時が短い人が残業して長く働き、休憩を取ったときは、本人が休憩を申請します

## 6. 「締め」の実施のお願い
- もう一度アナウンスしますが、原則毎月の「締め」を行ってください。こういったケースで「過去のデータをなるべく影響を受けさせない」ようにするための確定＆ロック機能です。締めていないと過去のデータも再計算されてしまいます。締め後に再度編集可能に戻すこともできますので、必ず行ってください。
- ただし**今月分（9/26〜10/25）だけは、こちらの計算し直しが終わってから承認・締めをしてください**（終わったらお知らせします）。締めた記録は計算し直しの対象外になるためです。先月までの分は、今すぐ締めていただいて大丈夫です。
- ※今月分は途中で計算方法が変わったため、計算し直しのあとに、労務管理者のチェックが必要です。
