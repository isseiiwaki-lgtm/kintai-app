# 勤怠システム 管理者への連絡事項（2026年10月の更新）

## 1. お願いしたい運用

### 打刻丸めの新しいスイッチ（次の締め期間の初日から）
- 会社設定に「15分丸め」と「残業を申請時刻までにする」の2つのスイッチが加わります
- 更新した時点では、どちらも OFF です
- **次の締め期間の初日（26日）に、2つとも ON にしてください**。月の途中で切り替えると、同じ月の中で計算方法が混ざってしまいます
- ※このスイッチは次回の更新で追加します。追加した時点で改めてお知らせします

### 休日出勤を代理打刻した月は「差し戻し」をしない
- 代理打刻で「休日出勤」にチェックした日がある月は、承認の取り消しや締め解除をしないでください
- やり直して承認すると、その日の遅刻・早退が0ではなくなってしまいます
- 次回の更新で直るまでの、一時的なお願いです

### 新しい社員を登録したら、すぐに本人に紐づけてもらう
- 登録したまま本人が紐づけていない状態が続くと、別の人がその社員として紐づけできてしまいます
- 登録したら、なるべく早く本人に Google アカウントでの紐づけを済ませてもらってください
- **管理者・承認者の方は、ご自身の紐づけが済んでいるか確認してください**
- 次回以降の更新で、登録時に「紐づけ予定の Google アカウント」を入力する仕組みに変える予定です

### 祝日の一括登録はしばらく行わない
- 祝日データの日付を直す作業を、こちらで行います
- 完了の連絡があるまで、休日カレンダーの「祝日一括登録」は行わないでください

## 2. 今回の更新で変わること

### Excel（個人別日別勤務報告書）
旧システム（勤怠Reco）と同じ読み方に戻します。列の位置と数は変わりません。
- **日付**：`11/5(水)` のように曜日が付きます
- **勤務時間**：`09:00-15:00` のように、記録された時間帯を表示します（これまでは時間の長さでした）
- **出勤・退勤**：実際に打刻した時刻を表示します。打刻していない日（代理打刻・管理者の入力・打刻修正申請で作った日など）は空欄です
- **変更出勤・変更退勤**：出勤・退勤の時刻を直した日だけ、出勤・退勤の両方を表示します。直した側は直した時刻、直していない側は打刻した時刻です。代理打刻した日もここに表示されます。それ以外の日は `-` です
- **遅刻／早退**：`遅 0:30` / `早 2:00` のように区別して表示します。両方ある日は `遅 0:30 早 1:00` と並べます。**文字が入るため、Excel 上で合計などの計算には使えません**
- **祝日**：山の日などの祝日が1日前にずれて表示されていた不具合を直します（祝日データの修正後に反映されます）
- 承認前の日も、遅刻・早退が表示されるようになります

### 勤怠承認
- 一覧画面の「承認」ボタンでも、遅刻・早退・残業の時間が正しく記録されるようになります（これまでは承認詳細画面からの承認でしか記録されていませんでした）
- 一覧画面の「承認」で、「提出済」の日もまとめて承認されるようになります
- **「締め解除」ボタンを追加します**（ADMIN のみ）。締めた後に間違いが見つかった場合に、「承認済」の状態に戻せます。解除した記録は変更履歴に残ります

### ユーザー管理
- **ユーザーの複製が使えるようになります**。複製したユーザーは、会社メールを入力して保存すれば、本人が紐づけできます
  - 複製で登録済みの佐藤さんは、編集画面で会社メールを保存し直してから、本人に紐づけてもらってください
- 他の人と同じ社員番号を入れると、エラーメッセージが出て保存されません
- CSV 取り込みで他の人と同じ社員番号があると、その行がエラーになります（これまでは他の人の番号が自動で消されていました）
- 出勤・退勤時刻は、15分刻み（00・15・30・45分）以外は登録できません

### 社員の画面
- 遅刻・早退の申請を出すと、その日の「要確認」が「申請中」に変わり、承認されると消えます
- 遅刻の申請は遅刻の分だけ、早退の申請は早退の分だけを消します。退勤の打刻漏れは、打刻修正申請で直すまで「要確認」のまま残ります

### 紐づけ画面
- 紐づけ用のリンクの有効期限が15分になります
- 期限が切れた場合や紐づけできなかった場合は、「リンクの有効期限が切れました。もう一度ログインしてください」と表示されます。もう一度 Google でログインし直してください

## 3. ご要望への回答

### 社員番号の変更
- 変更して問題ありません。勤怠の記録はそのまま引き継がれます
- 他の人と同じ番号は使えません
- 給与ソフト側で社員番号を使っている場合は、給与ソフト側の対応も直してください

### 承認経路で、同じステップに承認者を2名置きたい（例：step1 を2名）
- 今のシステムではできません（同じステップに登録すると上書きされます）
- 「2名のうちどちらか1名が承認すれば次へ進む」形で、次々回の更新で対応する予定です
- 「2名とも承認が必要」な場合は、今でもステップを分けて登録すれば同じことができます

### 打刻を一度もしていない日に、働いた記録を追加したい
- **管理者が入れる場合**：承認詳細画面の「代理打刻」で、出勤・退勤をまとめて入力できます。保存すると「承認済」になります
- **社員本人が入れる場合**：申請メニューの「打刻修正申請」で、日付を選んで出勤と退勤を**それぞれ1件ずつ（合計2件）**申請してください。勤怠記録の画面にはその日の行が無いため、修正依頼ボタンからは申請できません
- マニュアルにも追記する予定です

## 4. 確認していただきたいこと

1. **振替休日・国民の休日**：祝日一括登録では、振替休日（例：2026年5月6日）と国民の休日（例：2026年9月22日）が登録されません。これまで手動で追加していたかどうかを教えてください
2. **Excel の遅刻／早退欄**：この欄の数値を、Excel の計算式や給与ソフトへの取り込みで使っていないか教えてください（今回の更新で文字入りの表示になります）
3. **Excel の見た目**：更新後に一度 Excel を出力し、日付や勤務時間の欄で文字が途中で切れていないか確認してください
