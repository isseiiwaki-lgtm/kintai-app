# VPS リソース余裕の見込み（2026-11-12 時点）

目的：今のVPSにサービスを追加するか（スケールアップ／スケールアウト）、他のSaaSを使うかを比べるための材料。

- 対象：KAGOYA VPS（133.18.123.23）。プランは 2コア / 2GB RAM / 200GB
- 取得方法：SSH（ubuntu ユーザー）から読み取り専用のコマンドで取得。設定は変更していない
- 過去の記録：sysstat（sar）の 11/4〜11/12 分。10分ごとの記録

---

## 1. 結論

- **普段の稼働時**：CPUにはかなり余裕がある。メモリは中程度の余裕で、追加できるのは軽いサービス1つ程度。
- **ビルド時**：ここが一番きつい。実メモリの空きは約0.9GBで、Next.js のビルドを稼働中のサービスと並べて走らせると、スワップを使い切る手前まで行く可能性が高い。
- サービスを同じVPSに足すなら、**メモリを4GBに上げる**のが先。CPUは2コアのままで足りる。

## 3. ビルド時の推定

`~/deploy.sh` は VPS 上で次の順に実行する。

1. `git pull`
2. `npm ci`
3. `npx prisma generate` / `npx prisma migrate deploy`
4. `npm run build`（`next build`）
5. `pm2 restart kintai`

**ビルドの間も古いアプリと n8n は動いたまま。**

sar は10分おきの記録なので、ビルド中の瞬間的な山は残っていない。本番でビルドを試すこともしていない。以下は Next 16 の一般的なビルド時メモリ（1〜1.5GB）からの推定。

- 空き0.9GBに対してビルドが1〜1.5GBを必要とするので、**0.3〜0.6GBほどスワップに追い出される**。
- これまで OOM が起きていないのは、スワップ2.8GBがあるおかげ。ディスクへの退避で遅くはなるが、ビルドは通っている。
- 普段使うメモリが+300〜500MB増えると、ビルド時に OOM が起きるおそれがある。

## 4. 判断材料

### 4-1. 選択肢の比較

| 選択肢 | 向いているケース | 長所 | 短所 |
|---|---|---|---|
| **今のVPSのまま** | 追加するのが200MB以下の軽いもの（cron スクリプトなど）だけのとき | 費用・手間が増えない | ビルド時の余裕がさらに減る |
| **4GBにスケールアップ** | Node・Python のサービスを1〜2個追加したいとき | ビルドの不安もなくなる。一番手間が少ない | 月額が上がる。プラン変更時に再起動が要る可能性 |
| **2台目のVPSに分ける（スケールアウト）** | 勤怠アプリを他から切り離したいとき | 障害やデプロイの影響を受けない | 管理の手間（更新・バックアップ・証明書）が2倍になる |
| **SaaSに切り出す** | n8n（370MB）を n8n Cloud や Make に移す場合など | 今のVPSのまま余裕ができる | 月額費用がかかる。社内DBに直接つなぐ連携は作りにくくなる |

### 4-2. 目安

| 追加したいもの | 推奨 |
|---|---|
| 軽い cron スクリプト・小さな Python ツール（〜200MB） | 今のVPSのまま |
| Node / Python の常駐 Web サービス 1〜2個 | 4GB にスケールアップ |
| 勤怠アプリへの影響を避けたい重要サービス | 2台目のVPS か SaaS |
| ワークフロー自動化（n8n 相当） | n8n をそのまま使う／SaaS に移すかを先に決める |

### 4-3. 手元で今すぐできる対策（任意）

| 対策 | 見込み | 注意 |
|---|---|---|
| n8n を止める | 約370MB 空く | n8n の通知は今もつながっていない。使う予定があるなら止めない |
| dockerd を止める | 約75MB 空く | コンテナを使っていないか先に確認が必要 |
| ビルドを手元PCや GitHub Actions で行い、成果物だけVPSに送る | ビルド時の不安がなくなる | `deploy.sh` とデプロイ手順の変更が要る |

## 5. 確認できなかったこと

- ビルド中のメモリの山（実測はない。必要ならビルド中に `free -m` を数秒おきに取って確認する）
- docker のコンテナの中身（ubuntu ユーザーに docker の権限がない）
- KAGOYA のプラン料金（上位プランの月額は KAGOYA の料金表で確認が必要）
