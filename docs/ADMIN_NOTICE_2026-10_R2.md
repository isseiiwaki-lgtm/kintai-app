# 勤怠システム 管理者への連絡事項（2026年10月の更新・第2弾）

打刻した時刻（実際にボタンを押した時刻）は、今回の更新でも消えたり書き換わったりしません。変わるのは、そこから計算する勤務時間・残業・休憩などの出し方です。

## 1. お願いしたい運用

### 更新した直後にお願いしたいこと
- **野﨑さん・羽山さんの「フルタイムパート」を設定してください**：ユーザー管理の編集画面に「フルタイムパート」のチェックが加わります。チェックした人だけ、パートでも半日の有給（午前／午後）を申請できます
- **上の設定の後、8/26 野﨑さんの有給申請を保存し直してください**：申請承認の画面の「処理済み」を 2026年9月 に戻し、その申請の「修正」を開いて、そのまま「保存」を押してください。これまでの不具合で、Excel の有給の集計に入っていなかった申請です。保存し直すと、午後休として計算し直されます

### 次の締め期間の初日（10月26日）の朝、業務開始前にお願いしたいこと
会社設定の画面で、次の2つを変更してください。月の途中で切り替えると、同じ月の中で計算方法が混ざってしまいます。
- **スイッチ③④⑤を ON にする**（①②は ON のまま）
  - ③ 15分丸め
  - ④ 残業を申請の時刻までにする
  - ⑤ 新しい計算方式（休憩と残業の出し方。下の「3. 計算の変わり方」を参照）
- **休憩時間控除ルールの「ルール1」を「360分超で60分」にする**（ルール2の「480分超で60分」はそのまま）
  - 6時間を超える勤務は休憩60分、6時間以下は休憩なし、になります。例：定時 9:00〜17:00 の人の所定は 7:00
  - 休憩が60分でない人は、ユーザー管理の「所定休憩」で個別に設定してください
  - ルールの欄は空にしないでください

### 「一括再計算」は押さないでください
- 押すと、締めていない過去の日がすべて新しい計算で出し直され、給与計算が済んだ月の数字も変わります
- 給与計算が済んだ期間（〜9/25 など）は、できれば「一括締め」をしておいてください。締めておけば、後から承認し直しても数字は変わりません

### 社員への周知をお願いしたいこと
- **パート**：打刻画面の「休憩開始・休憩終了」がなくなり、休憩の分数ボタン（0・15・30・45・60分）に変わります。その日の休憩の合計を押してください。60分を超える休憩や押し忘れは「休憩申請」で出してください
- **正社員**：定時より前に退勤した日は、原則として**その日のうちに早退申請**を出してください。申請の中で「休憩を取りましたか」に答えてもらいます（退勤時刻だけでは休憩を取ったか分からないため）。退勤した直後の画面に、申請を促す表示が出ます
- **休日出勤**：「休日出勤申請」を出してください。代わりに休む日を一緒に決めると「振休」、後から決めると「代休」になります（※原則として行わず、代休は避けられない理由により上長の承認を得た時のみ）。休日出勤の日の休憩も、この申請で入力します
- **振休申請は休日出勤申請**に統合されました（これまでの振休のデータはそのまま残ります）。

### 前回のお願いの取り下げ
- 「休日出勤を代理打刻した月は差し戻しをしない」のお願いは、今回の更新で不要になります。休日出勤の印が保存されるようになり、承認し直しても遅刻・早退が0のまま保たれます

## 2. 今回の更新で変わる画面

### 社員の画面
- **打刻画面**：休憩開始・休憩終了のボタンがなくなります。パートには休憩の分数ボタンが出ます
- **申請**：「休憩申請」「休日出勤申請」が加わり、「振休申請」がなくなります。正社員の早退申請には「休憩を取りましたか」の欄が加わります
- **有給**：同じ日に有給の申請は1件までです（同じ日に午前と午後を分けて出すことはできません。1日休む場合は全日で申請してください）

### 管理者の画面
- **承認詳細**
  - 「管理者の修正を取り消す」ボタン：管理者が直した時刻を、1つ前の状態に戻せます
  - 編集画面に「休憩（分）」と「休日出勤（代理）」が加わります
  - 振休・代休で休む日に「振休（10/12 出勤分）」のように表示されます
  - 「申請あり」を押すと、その日の締め期間の申請承認の画面が開き、該当の申請が目立って表示されます
- **勤務状況一覧**：「休憩記録なし」「休日申請なし」の列が加わります（該当する日があるときだけ）。更新より前の日は休憩ボタンがなかったため、パートの「休憩記録なし」が多く出ますが、気にしなくて大丈夫です
- **申請承認**：休暇の修正画面の「半日」が「取得単位（全日／午前／午後）」になります。修正画面を開いても、画面の位置が上に飛ばなくなります
- **会社設定**：スイッチ⑤「新しい計算方式」が加わります
- **ユーザー管理**：「所定休憩（分）」と「フルタイムパート」が加わります
- **Excel**：「代休」の列が加わります。休む日の行に「振休（10/12 出勤分）」のように表示されます

## 3. 計算の変わり方

### 更新した日から変わること
（仕組み上正しいが、実際の制度との差等で発生していた数字の誤り修正）

- **午前半休の日**：午後から出勤しても遅刻になりません（例：午前半休で 13:00 出勤 → これまでは遅刻4時間 → 遅刻なし）
- **半休の有給の時間**：所定の半分ではなく、12:00〜13:00 を境にした本人の時間で記録します（例：定時 8:30〜17:30 の人 → 午前休 3:30、午後休 4:30）
- **休日に休日出勤申請なしで出勤した日**：遅刻・早退は付きません。本人と管理者に、申請を促す表示が出ます
- **パートが休みの曜日に出勤した日**（シフトの入れ替え）：本人の定時がある、通常の勤務日として扱います。遅刻・早退も付きます。申請は不要です。ただし休日手当をつける場合は申請を行わせてください。
- **残業・早出の申請がある日の端数**：定時から14分以内の端数を定時にそろえる丸め（②）が、申請がある日にも効きます（例：残業申請がある日の 17:40 退勤 → 17:30）
- **管理者が直した時刻・代理打刻した時刻**は、丸めずにそのまま記録します（ただし原則として15分刻みのため、実際は丸めたものと同様の数値になるはずです）
- これらは、その日に打刻・申請・管理者の修正などがあったときや、月の一括承認をしたときに反映されます。何もない過去の日の数字は変わりません

### 10月26日にスイッチを ON にした日から変わること
定時 9:00〜17:30 の正社員の例です。

| ケース | これまで | 10月26日から |
|---|---|---|
| 9:20 出勤・18:00 退勤 | 残業 退勤時0・承認後10分 | 残業30分・遅刻20分 |
| 8:00 出勤・16:30 退勤（早出して早退） | 残業0 | 残業60分・早退60分（差し引きしない） |
| 残業申請が 18:00 までで 18:40 退勤 | 18:40 まで残業 | 18:00 まで残業（申請の時刻まで） |
| 定時 9:00〜17:00 の人の所定 | 7:15 | 7:00（休憩60分） |
- 10月25日までの記録は、計算し直しても、これまでの計算方式のままです

## 4. 今回の更新の背景（ご要望と対応）

9月にいただいたご要望に応えて正しい時間を出すには、これまで画面・Excel・承認でばらばらだった計算を、1つの決まった手順にまとめ直し、大きく変更する必要がありました。今回の計算方法の変更は、そのためのものです。

| ご要望・課題 | 対応 |
|---|---|
| 野木さんの勤務条件の変更（月火水 9:00〜15:00・休憩60分） | 個別の「所定休憩」追加。会社設定の休憩基本ルール追加 |
| フルタイムパートの有給（半休）利用可能 | 半休の申請基準の変更、個人別設定・計算処理を追加 |
| パート休憩をボタンで申請 | 休憩ボタン設置。本人が記録。60分を超える休憩や押し忘れは休憩申請 |
| 丸め処理の多層化 | 実打刻と計算を分離し、スイッチで計算を切り替える形に変更 |
| 休日出勤を代理打刻した日を承認し直すと、遅刻・早退が付いてしまう | 休日出勤の印を保存、休日出勤申請（振休・代休）を追加 |
| 画面と Excel で残業の出し方が違う | 旧来の勤怠Recoに引きずられていたまちまちだった計算を一元化し、すべて同じ計算を通す形に変更 |
| 複製で作ったユーザーが、本人の Google アカウントと紐づけできない | 複製しても対応可能に改修 |
| 承認経路で、同じステップに承認者を2名置きたい | 「2名のうちいずれかが承認すれば次へ進む」形に改修 |

前回の更新（10月6日リリース）で対応済みの要望：

## 5. 確認していただきたいこと

1. **野木さんの設定**：ユーザー管理で、所定出勤曜日（月火水）・定時（9:00〜15:00）・所定休憩（60分）が設定されているか確認してください。所定休憩を入れると所定が 5:00 になり、休憩ボタンの押し忘れも知らせが出るようになります
2. **パートの所定出勤曜日**：休みの曜日に出勤した日を「シフトの入れ替え」として扱うため、ユーザー管理の「所定出勤曜日」が実際の勤務の曜日と合っているか確認してください
3. **会社の休み**：休日カレンダーに、祝日以外の会社の休み（年末年始など）が登録されているか確認してください。登録された日の出勤は休日出勤として扱います
4. **法定休日と週の起算日**：Excel の残業の振り分けのため、仮に定めがない場合の規定である「日曜」はじまりとしています。就業規則に記載があれば正しい曜日を教えてください（普通日曜か月曜で、休日振替の都合で土曜にすることがあります）
