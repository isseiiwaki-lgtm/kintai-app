# 実装状況 & タスク管理

最終更新: 2026-04-22

## 実装済み（動作確認済み）

### 一般ユーザー機能
- **ホーム** `/` — 今日の打刻状態・出退勤時刻・勤務時間、今月の実績（出勤日数・合計時間）
- **打刻** `/clock` — 出勤・退勤・外出・戻り・休憩開始/終了。開発用デバッグパネルあり
- **勤怠記録** `/records` — 月次一覧（日付/曜日/出退勤/残業/状態バッジ）、月提出ボタン、前後月ナビ
- **申請** `/requests` — 申請一覧・キャンセル機能
- **申請 新規** `/requests/new` — 残業申請/遅刻早退/休暇申請（有給・代休・半日）/修正依頼/その他

### 管理者機能 (ADMIN/APPROVER)
- **勤務状況一覧** `/admin/attendance` — 全ユーザー月次一覧、前後月ナビ
- **勤怠承認** `/admin/approval` — ユーザー別ステータス集計、承認操作 (ApprovalActions コンポーネント)
- **申請承認** `/admin/requests` — 申請一覧・承認/却下操作
- **休日カレンダー** `/admin/holidays` — 祝日一括シード、手動追加・削除
- **ユーザー管理** `/admin/users` — 一覧・新規作成・編集・削除、CSVインポート/エクスポート

### 認証
- Google OAuth (NextAuth v5) + JWT戦略
- 未登録Googleアカウント → `/link` で会社メールと紐付け
- ADMIN/APPROVER/EMPLOYEE の3ロール

## 懸念事項

- **打刻の時刻丸め** — 現在は生時刻を保存。会社の丸めルール（例: 15分単位）が必要か要確認
- **勤務時間計算** — workingMinutes の更新タイミングと外出/休憩控除のロジックを要確認
- [ ] **LeaveBalance テーブル** — migration 済みか未確認。actionDeleteUser で `.catch(()=>{})` で握り潰している
- [ ] **外出・休憩の複数回問題（要仕様確認）** — 現在 `goOutAt/returnAt`・`breakStart/breakEnd` は各1ペアのみ保持。2回目の外出/休憩打刻で1回目の記録が上書き消滅し、退勤時の勤務時間計算も最後の1回しか控除されない。対応方針を決める必要あり：
  - A) 現行のまま（1日1回外出を前提とし、複数回は修正依頼で対応）
  - B) スキーマに `GoOutLog[]` テーブルを追加して複数回対応
