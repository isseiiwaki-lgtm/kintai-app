# SSH接続手順書

## はじめに

VPSはサーバーの操作に際して、グラフィカルな操作画面（GUI）はありません。すべて**コマンドライン（CLI）**と呼ばれる真っ黒な画面から操作します。  
特にSSH（Secure SHell）でWebサーバーにログインするものを**ターミナル**といいます。SSHはFTPなどと同じログイン方法の一種です。パスワードではなく事前にサーバーとPCに保存した2つの鍵を使います。  
「コマンドライン操作のために」「ターミナルの一種である」「PowerShellを使って操作する」と覚えておいてください。サーバーへの操作を行う時はSSHログインを行います。  

## 通常のショートカットキーと異なるCLI操作（主なもの）

- 移動や削除

| キー | 動作 | 備考 |
| :--- | :--- | :--- |
| **Ctrl + V** | 貼り付け | Ctrl + Shift + V の場合も |
| **Ctrl + A** | 行の**先頭**に移動 | GUIでは「全選択」ですが、CLIでは「Home」キーの役割 |
| **Ctrl + E** | 行の**末尾**に移動 | 「End」キーと同じ役割 |
| **Ctrl + ← / →** | **単語単位**で移動 | 長いパスを入力している時 |
| **Ctrl + U** | 行の**先頭まで**すべて削除 | 入力をやり直したい時 |
| **Ctrl + K** | カーソルから**末尾まで**削除 | 後半部分だけ書き換えたい時 |
| **Ctrl + L** | 画面を**クリア**する | `clear`コマンドを打つのと同じ効果 |

- 履歴の呼び出しと重要な操作

| キー | 動作 | 備考 |
| :--- | :--- | :--- |
| **↑ / ↓** | 履歴を一つずつ遡る / 進む | 過去のコマンドをもう一度打ちたい時 |
| **Ctrl + R** | **履歴のインクリメンタル検索** | **重要。** 過去に打ったコマンドの一部から検索 |
| **Tab** | **コマンドやファイル名の補完** | 数文字打ってTabを押すだけで、正確な名前を補完 |
| **Ctrl + C** | 実行中の処理を**強制終了** | コピーではなく「中断」 |
| **Ctrl + Z** | 入力の終了（EOF） | ファイル作成中などに「ここで終わり」と伝える合図 |

## 必要なもの

- 秘密鍵ファイル（`id_ed25519`）※別途受け取ったファイル

---

## 手順1：秘密鍵ファイルを保存する

1. 受け取ったテキストを`id_ed25519` というファイル名で保存する
2. ファイルを移動
   - 保存場所：`C:\Users\（あなたのユーザー名）\.ssh\` フォルダ
   - `.ssh` フォルダが存在しない場合は新しく作成する
3. ファイル名の末尾に `.txt` がついていないか確認する（例：`id_ed25519.txt` はNG）

> **拡張子の確認方法：** エクスプローラーの「表示」→「ファイル名拡張子」にチェックを入れると確認できます。

---

## 手順2：PowerShell を開く

1. スタートメニュー → `PowerShell` と検索して起動する
2. または `Windows キー + R` →「PowerShell」と入力してEnter

---

## 手順3：SSH接続する

PowerShell に以下のコマンドを入力してEnterを押す：

```
ssh -i $HOME\.ssh\id_ed25519 issei@133.18.123.23
```

`Ctrl + V` で貼り付けできないときは `Ctrl + shift + V`
初回接続時に以下のメッセージが表示された場合は `yes` と入力してEnterを押す：

```
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

---

## 接続できたら

以下のようなプロンプトが表示されれば成功です：

```
issei@v133-18-123-23-vir:~$
```

---

## よく使うコマンド

| 操作 | コマンド |
|------|---------|
| n8n を再起動する | `sudo systemctl restart n8n` |
| n8n の状態を確認する | `sudo systemctl status n8n` |
| n8n を停止する | `sudo systemctl stop n8n` |
| n8n を起動する | `sudo systemctl start n8n` |
| SSH接続を終了する | `exit` |

---

## うまくいかない場合

- 秘密鍵ファイルの保存場所・ファイル名が正しいか
- ファイル名に `.txt` などの拡張子がついていないか
- コマンドを正確にコピー＆ペーストしているか

それでも解決しない場合はエンジニアに連絡してください。
